# Hokorobi actor — systemic resilience observatory

Canonical repository: `etzhayyim/actor-hokorobi`.

Hokorobi is an observation organ of the Tamaki artificial organism. It maps
publicly disclosed systemic-finance relationships and prepares resilience
observations; it is not an independent financial authority, solvency assessor,
trading signal, or investment adviser.

Live ingestion and outward publication remain behind the existing Council,
operator-DID, sourcing, and audit gates. Hokorobi must never bypass those gates
or turn representative edge weights into verdicts about an institution.

The stable actor identity remains `did:web:etzhayyim.com:actor:hokorobi`.

See `CLAUDE.md` and `manifest.edn` for the complete constitutional boundaries.
